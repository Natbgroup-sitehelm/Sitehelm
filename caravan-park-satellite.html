⚙️ Backend Endpoint — Required for live payments

Your server needs one endpoint that creates a Stripe PaymentIntent and returns the client_secret. Here's the Node.js code:

// Node.js / Express
const stripe = require('stripe')(process.env.STRIPE_SECRET_KEY);

app.post('/create-payment-intent', async (req, res) => {
  const { amount, currency, bookingId } = req.body;
  const intent = await stripe.paymentIntents.create({
    amount,          // in cents, e.g. 5500 = A$55.00
    currency,        // 'aud'
    metadata: { bookingId },
  });
  res.json({ clientSecret: intent.client_secret });
});

// For refunds:
app.post('/refund', async (req, res) => {
  const { paymentIntentId, amount } = req.body;
  const refund = await stripe.refunds.create({
    payment_intent: paymentIntentId,
    amount,          // partial or omit for full refund
  });
  res.json({ refund });
});

Deploy this to Heroku, Railway, Render, or any Node host. Set STRIPE_SECRET_KEY as an environment variable — never put it in the browser.

📱 Wall QR Code — Clock On/Off Terminal

Print this QR code and stick it on the wall near the entrance. Staff scan it with their phone camera and enter their PIN to clock on or off. No app needed — works on any smartphone.

Scan with phone camera
How it works:
1 Print the QR code and stick it on the wall near the park entrance or office
2 Staff open their phone camera and point it at the QR code
3 The clock-on page opens automatically — they tap their 4-digit PIN
4 Instantly clocked on or off — the clock log updates in this app immediately
💡 Pro tip: For a permanent terminal, open clockon.html on a cheap tablet mounted on the wall. Staff tap the screen instead of scanning — no phones needed at all.
